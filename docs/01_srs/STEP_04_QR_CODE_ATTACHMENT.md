## ১. মডিউল পরিচিতি ও ব্যবসায়িক উদ্দেশ্য (Introduction & Objectives)

### ১.১ প্রেক্ষাপট
ধাপ ৩-এ থার্মাল প্রিন্টার থেকে প্রিন্ট হওয়া কিউআর কোড লেবেলগুলো সুইং সেকশনের অ্যাসেম্বলি টেবিলে পৌঁছায়। 
সুইং লাইনে যখন প্যান্টের সামনের পার্ট (Front Part) এবং পেছনের পার্ট (Back Part) সেলাই করে জোড়া লাগানো হয় (Assembly Stage - Side Seam / Inseam Join), ঠিক সেই মুহূর্তে এই কিউআর কোড লেবেলটি কাপড়ে স্থায়ীভাবে সেলাই বা ফিক্স করা হয়।

### ১.২ মূল উদ্দেশ্য
1. **শারীরিক কাপড়ের সাথে ডিজিটাল পরিচয়ের মিলন**: এই ধাপেই কাপড়ের ভৌত অস্তিত্বের সাথে তার ক্লাউড/ডাটাবেজের পরিচয়ের চূড়ান্ত সংযোগ ঘটে।
2. **লেজার স্ক্যানারের জন্য পজিশন স্ট্যান্ডার্ডাইজেশন**: প্রতিটি প্যান্টের ঠিক একই স্থানে (Standardized Fixed Position) কিউআর ট্যাগ লাগানো, যাতে পরবর্তীতে Jeanologia ফ্ল্যাট কনভেয়ার টেবিলে শোয়ানো মাত্র ফিক্সড স্ক্যানার কোনো খোঁজাখুঁজি ছাড়া তৎক্ষণাৎ কোড রিড করতে পারে।
3. **সাইজ মিসম্যাচ সম্পূর্ণ রোধ (Zero Size Mismatch)**: ফ্রন্ট ও ব্যাক জোড়া লাগানোর সময়ই অপারেটর সাইজ ভেরিফাই করে লেবেল লাগাবে। ফলে ভুল সাইজের ফ্রন্টের সাথে অন্য সাইজের ব্যাক জোড়া লাগার সুযোগ শূন্য হয়ে যায়।
4. **সুইং থেকে লেজারের ডিজিটাল হ্যান্ডওভার**: সেলাই সম্পন্ন হয়ে কত পিস প্যান্ট লেজার ওয়াশের উদ্দেশ্যে ট্রলিতে লোড হলো—তার ডিজিটাল ট্র্যাকিং নিশ্চিত করা।

## ৪. ফিজিক্যাল প্লেসমেন্ট স্ট্যান্ডার্ডস (Label Attachment Engineering Standards)

Jeanologia ফ্ল্যাট কনভেয়ার লেজার মেশিনের অটোমেশন নিখুঁত করার জন্য লেবেল লাগানোর স্থানটি কঠোরভাবে মানতে হবে:

### ৪.১ অনুমোদিত সেলাই পজিশন (Standardized Placement Position)
* **প্রাথমিক পজিশন (Primary - Recommended)**: ডানপাশের সাইড সিম (Right Side Seam), কোমরের বেল্টলাইন থেকে **৫ থেকে ৮ সেন্টিমিটার নিচে**।
  * *কেন এখানে?* ওভারলক বা সেফটি স্টিচ করার সময় অপারেটরের হাতের নাগালে থাকে এবং টেবিলে প্যান্ট সোজা বা উল্টো যেভাবেই শোয়ানো হোক, স্ক্যানার সহজে কোড রিড করতে পারে।
* **বিকল্প পজিশন (Secondary)**: পেছনের ডানদিকের বেল্ট লুপের (Back Right Belt Loop) ভেতরে অথবা কয়েন পকেটের ভেতরের দিকে।

### ৪.২ সেলাই ও ফিক্সিং স্পেসিফিকেশন
* লেবেলটি এমনভাবে সেলাই করতে হবে যেন কিউআর কোডের মুদ্রিত অংশের ওপর কোনো সেলাই না পড়ে (সিম অ্যালাউন্সের প্রান্তে সেলাই হবে)।
* লেবেল উপাদান: সিন্থেটিক ওয়াশেবল টিয়ার-অ্যাওয়ে পেপার অথবা সফট পলিয়েস্টার—যা আয়রনিং ও সুইংয়ের ঘষা সহ্য করতে পারে কিন্তু ড্রাই লেজার ওয়াশের পর সহজে রিমুভ করা যায়।

## ৫. কার্যকরী রিকোয়ারমেন্টস (Functional Requirements - FR)

### FR-QA-01: সাইজ ম্যাচিং পোকা-ইওকে (Assembly Size Poka-Yoke)
- অপারেটর যখন সাইজ ৩২-এর ফ্রন্ট পার্ট এবং ব্যাক পার্ট মেশিনে নেবে, তখন তাকে নিশ্চিত করতে হবে কিউআর লেবেলটিও **Size 32**।
- লেবেলের ওপর চোখের দেখায় সহজে চেনার জন্য বড় হরফে সাইজ (যেমন: **SIZE: 32**) লেখা থাকবে।

### FR-QA-02: ফিক্সড ওরিয়েন্টেশন রুল (Scanner Line-of-Sight)
- লেবেলটি এমনভাবে সেলাই করতে হবে যাতে কিউআর কোডের মুখ বাইরের দিকে (Face-Up) থাকে, কাপড়ের ভাজে ঢাকা না পড়ে।
- এর ফলে Jeanologia কনভেয়ারের ওপর থাকা ফিক্সড 2D স্ক্যানার কোনো মানুষের ছোঁয়া ছাড়াই কাপড় টেবিলের ওপর পড়ামাত্র ০.০৫ সেকেন্ডে কোড পড়তে পারবে।

### FR-QA-03: সেলাই লাইনের শেষ প্রান্তে বান্ডেল ভেরিফিকেশন (Line-End Verification)
- প্রতিটি সুইং লাইনের শেষে কিউসি টেবিলে ১টি ছোট হ্যান্ডহেল্ড ওয়্যারলেস বারকোড স্ক্যানার থাকবে।
- ২০ পিসের বান্ডেল সেলাই শেষ হলে কিউসি ইন্সপেক্টর বান্ডেলের যেকোনো ১টি প্যান্টে স্ক্যানার ছোঁয়াবে: `[BEEP!]`।
- স্ক্রিনে সাথে সাথে দেখাবে:  
  *✅ "Bundle #05 - Style 511 - Size 32 (20 pcs) - All Labels Successfully Attached!"*
- সাথে সাথে ডাটাবেজে ওই বান্ডেলের ২০টি পিসের স্ট্যাটাস আপডেট হবে: `garment_units.current_status = ATTACHED_IN_SEWING`।

### FR-QA-04: সেলাইয়ের সময় লেবেল নষ্ট হলে দ্রুত রিপ্লেসমেন্ট এসওপি
- সুইং সেলাইয়ের সময় অসাবধানতাবশত যদি কোনো কিউআর লেবেল কেটে যায় বা সুই দিয়ে ছিঁড়ে যায়:
  1. অপারেটর ছেঁড়া লেবেলটি লাইন সুপারভাইজারকে দেবে।
  2. সুপারভাইজার তার মোবাইল বা পিসি থেকে ওই বান্ডেল ও পিস নম্বর সিলেক্ট করে **[ Damaged Label Replace ]** রিকোয়েস্ট পাঠাবে।
  3. প্রিন্টিং স্টেশনে স্বয়ংক্রিয়ভাবে একটি নতুন লেবেল প্রিন্ট হবে যার ওপর **`[REPRINT-DAMAGED]`** লেখা থাকবে।
  4. নতুন লেবেলটি সেলাই করে বান্ডেলে যুক্ত করা হবে।

### FR-QA-05: ট্রলি লট ডিসপ্যাচ ও ডিজিটাল চালান (Line Transfer to Laser)
- যখন একটি ট্রলিতে ৫০০ বা ১,০০০ পিস কমপ্লিট প্যান্ট লোড হবে, সুইং সুপারভাইজার ব্রাউজারে গিয়ে **[ Transfer to Laser ]** বাটনে চাপ দেবে।
- সিস্টেম একটি ডিজিটাল ট্রান্সফার চালান (Digital Chalan No) তৈরি করবে:
  * যেমন: `CHALAN-SW04-TO-LSR-0089` (মোট পিস: ৫০০, সাইজ ৩০=২০০, সাইজ ৩২=৩০০)।
- সাথে সাথে লেজার ডিপার্টমেন্টের রিসিভিং ড্যাশবোর্ডে অ্যালার্ট আসবে: *"500 pcs in transit from Sewing Line #04"*; প্যান্টের স্ট্যাটাস হবে `TRANSIT_TO_LASER`।

## ৬. অকার্যকরী রিকোয়ারমেন্টস (Non-Functional Requirements - NFR)

### NFR-QA-01: সেলাই অপারেশনের গতি অক্ষুণ্ণ রাখা
- কিউআর লেবেলটি এমনভাবে ডিজাইনার ও রোল আকারে থাকবে যেন অ্যাসেম্বলি অপারেটরের প্রতি পিসে সেলাই করতে **১ থেকে ১.৫ সেকেন্ডের বেশি অতিরিক্ত সময় না লাগে**। সেলাই লাইনের এসএমভি (Standard Minute Value - SMV) প্রভাবিত হতে পারবে না।

### NFR-QA-02: তাপ ও প্রেসার রেজিস্ট্যান্স (Heat & Ironing Proof)
- সুইং লাইনের মিডল প্রেসিং বা আয়রনিংয়ের সময় লেবেলটি ২০০ ডিগ্রি সেলসিয়াস তাপমাত্রায় গলে যাওয়া বা কিউআর কোড ব্লার হওয়া সম্পূর্ণ নিষিদ্ধ।

## ৭. ডেটাবেজ স্কিমা স্পেসিফিকেশন (Database Schema for Step 4)

ধাপ ৪ পরিচালনার জন্য PostgreSQL 16-এ নিচের টেবিল ও সম্পর্কগুলো ব্যবহৃত হবে:

### টেবিল ১: `sewing_lines` (সুইং লাইন মাস্টার)
```sql
CREATE TABLE sewing_lines (
    id UUID PRIMARY KEY, -- RFC 9562 UUIDv7
    line_name VARCHAR(50) NOT NULL UNIQUE, -- Line 01, Line 02, Line 04 ইত্যাদি
    floor_number VARCHAR(20),
    supervisor_name VARCHAR(100),
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    is_deleted BOOLEAN DEFAULT FALSE
);
```

### টেবিল ২: `sewing_dispatches` (লেজারে পাঠানোর ডিজিটাল চালান টেবিল)
```sql
CREATE TABLE sewing_dispatches (
    id UUID PRIMARY KEY, -- RFC 9562 UUIDv7
    dispatch_number VARCHAR(50) NOT NULL UNIQUE, -- CHALAN-SW04-TO-LSR-0089
    sewing_line_id UUID NOT NULL REFERENCES sewing_lines(id) ON DELETE RESTRICT,
    order_id UUID NOT NULL REFERENCES orders(id) ON DELETE RESTRICT,
    total_garments_count INTEGER NOT NULL CHECK (total_garments_count > 0),
    dispatched_by UUID, -- সুপারভাইজারের ইউজার আইডি
    status VARCHAR(30) DEFAULT 'IN_TRANSIT', -- IN_TRANSIT, RECEIVED_FULL, RECEIVED_SHORTAGE
    notes TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    is_deleted BOOLEAN DEFAULT FALSE
);
CREATE INDEX idx_sewing_dispatches_order ON sewing_dispatches(order_id);
CREATE INDEX idx_sewing_dispatches_status ON sewing_dispatches(status);
```
